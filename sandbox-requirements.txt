# ============================================
# 沙箱基线依赖（CodeAct 的能力边界）
# ============================================
#
# 装到**你的系统 Python 环境**里，一次就够：
#
#   python -m pip install -r sandbox-requirements.txt
#   python -m playwright install chromium        # 见文件末尾说明
#
# 为什么装到系统环境、而不是装进沙箱 venv：
# 这是**基线**依赖 —— 由你一次性、有意识地装好。沙箱 venv 用
# `--system-site-packages` 创建，会把这些直接借过来用，不必装两份
# （playwright 带 chromium 上百 MB，装两份纯浪费磁盘）。
#
# venv 要隔离的从来不是这一半，而是**模型中途要的临时依赖** ——
# 那些经 run_command 装（每次请你确认），落在 venv 自己的 site-packages 里，
# 碰不到这里。于是两类依赖的边界正好和「谁做的决定」对齐：
#   你的决定  → 系统环境（基线，稳定，可复用）
#   模型的决定 → venv（临时，可撤销，删掉重建即可）
#
# 用 `>=` 而不是锁死版本，是刻意的：这个文件装进的是**共享环境**，
# 锁死会让 pip 去升/降你别的项目在用的包 —— 那正是要避免的冲突。
# 下限取的是实测跑通的版本。若要完全可复现，把它装进独立环境再锁死。
